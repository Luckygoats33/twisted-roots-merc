# Print Copy — Vistaprint

Everything here is written to be set in the store's own type: Rye for the carved-sign display lines, Bitter for headings, Public Sans for body. Cream or paper background, bark brown and rust ink, amber only where something needs to be found in a hurry.

Read this before ordering anything:

---

## The QR rule

**Nobody is ever made to scan anything.**

Every printed piece that carries a QR code also carries, in type a 70-year-old can read across a counter without glasses:

1. the plain web address, spelled out, and
2. the line **"or just tell us at the counter."**

The QR code is the small thing in the corner. The address and the counter are the main path. If a piece only has room for one of the three, the QR is the one that gets cut.

Minimum type size for a printed URL on any piece: **10pt**. On signage, 24pt. QR codes print at **0.8 inch minimum** on paper goods, 2 inches on signage, always with a quiet border around them, always black on a light background — a QR reversed out of a dark photo scans badly in a store with no window light.

---

# 4. In-store signage

House rules for the whole set:

- **Stock:** rigid **foam board, 3/16", matte laminate** for department signs and the door. Foam board is light enough to hang on a shelf standard with two zip ties, cheap enough to reprint when a department changes, and matte so the overhead lights do not blow out the type.
- **The counter cards and the suggestion station** get **16pt matte card stock in a clear acrylic stand**, not foam board — they sit at eye level and get handled.
- **Type:** department name in Rye or Bitter Black at a size readable from across the store, the line underneath in Public Sans, the URL in Public Sans at 24pt minimum.
- **Every sign with a QR gets the printed short link and the "tell us at the counter" line.** No exceptions.
- **QR size on signage:** 2 inches, bottom right, black on cream, quiet zone all around.

# Before anything is ordered

- [ ] **Replace the phone number.** (541) 555-0134 is a placeholder and it is on eleven of these pieces. Search this file for `5550134`.
- [ ] Confirm the street address that goes on print — the site uses 151 N Gaither St throughout. If the mailing address is 101, everything here changes and so does the Google profile.
- [ ] Set up the short links in the table at the top. Print the QR codes from those short links, not from the long page URLs.
- [ ] Scan every QR code off a **printed proof**, not off the screen, with an older phone, in the store's actual light. A code that scans on a monitor and fails under fluorescents has failed.
- [ ] Read every piece out loud. If a line sounds like an advertisement, cut it.
- [ ] Check there is not a single exclamation point anywhere in the set.
